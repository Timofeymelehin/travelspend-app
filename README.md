# ✈️ TravelSpend — Учет расходов в путешествиях (Android / Web / PWA)

Красивое, быстрое и полностью автономное приложение для учета расходов в путешествиях с нативной поддержкой Android, автоматической конвертацией валют, аналитикой трат и PIN-защитой.

Изначально создано на базе таблицы **«Затраты в Японии»** и расширено до универсального трекера любых путешествий по миру.

---

## 🌟 Ключевые возможности

- 🇯🇵 **Пресет «Затраты в Японии»**: предзаполненные категории (Транспорт, Отели, Еда, Билеты, Сувениры и т.д.) с расчетами в иенах (JPY) и рублях (RUB).
- 🌍 **Мультивалютность и курсы ЦБ**:
  - Автоматическая подгрузка свежих биржевых курсов валют (JPY, RUB, USD, EUR, THB, GEL, KZT и др.).
  - Возможность задать ручной/фиксированный курс (по какому курсу вы реально меняли наличные или платили картой).
  - Быстрый встроенный валютный конвертер.
- 📶 **100% Офлайн-доступ (Offline-First)**:
  - Работает в авиарежиме, метро и в роуминге без доступа к интернету.
  - Все расходы и курсы валют кэшируются локально на устройстве.
- 📊 **Наглядная аналитика и графики**:
  - Круговая диаграмма распределения трат по категориям.
  - Индикаторы остатка бюджета и дневного лимита.
  - Сравнение наличных платежей и оплаты картой.
- 🔒 **Безопасность и конфиденциальность**:
  - 4-значный PIN-код с защитой от подбора (хэширование SHA-256).
  - Автоблокировка при сворачивании приложения.
  - Режим «Скрыть суммы» (Eye Mask) для безопасного просмотра в людных местах.
- 📑 **Экспорт и импорт**:
  - Полная совместимость с Excel и Google Таблицами (экспорт/импорт в формате CSV).

## 📱 Как собрать нативный Android APK

### Вариант 1. Автоматическая сборка APK через GitHub Actions (в облаке)
В репозитории уже настроен пайплайн `.github/workflows/build-android-apk.yml`:
1. Перейдите во вкладку **Actions** вашего GitHub-репозитория.
2. Выберите воркфлоу **«Build Android APK»** и нажмите **«Run workflow»**.
3. Дождитесь завершения сборки (~2-3 минуты) и скачайте готовый файл **`travelspend-debug.apk`** из раздела **Artifacts**.

### Вариант 2. Сборка на компьютере через Android Studio
```bash
# Клонируйте репозиторий
git clone https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git
cd travelspend

# Установите зависимости
npm install
npm install @capacitor/core @capacitor/android
npm install -D @capacitor/cli

# Соберите проект и сгенерируйте Android-папку
npm run build
npx cap add android
npx cap sync android

# Откройте проект в Android Studio
npx cap open android
```
В Android Studio выберите: **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**. Готовый `.apk` появится в `android/app/build/outputs/apk/debug/`.

## 🌐 Установка как PWA прямо из браузера (без сборки)

- **Android (Chrome)**: Откройте ссылку на сайт, нажмите на три точки (⋮) и выберите **«Установить приложение»**.
- **iOS (Safari)**: Нажмите кнопку **«Поделиться»** (квадрат со стрелкой) → **«На экран Домой»**.
